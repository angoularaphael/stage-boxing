Cahier des charges simplifié — Page de vente 
des stages enfants Boxing Center
1. Objet du projet
Créer une page web dédiée à la présentation et à la vente des stages enfants Boxing Center.
Cette page aura pour objectif de :
• présenter les stages enfants à venir ;
• donner envie aux enfants de participer ;
• rassurer les parents sur le contenu, l’encadrement, la sécurité et le sérieux du stage ;
• permettre l’achat et l’inscription en ligne ;
• orienter rapidement les familles vers la bonne salle : Boxing Center Portet-sur-Garonne 
ou Boxing Center Minimes.
La page pourra être hébergée sur un sous-domaine Boxing Center, par exemple :
stages.boxingcenter.fr
ou tout autre sous-domaine validé par la direction.
2. Stage concerné
Le premier stage à intégrer sera :
Les Vacances des Boxeurs
Il s’agit d’un stage de boxe anglaise prévu du 26 au 31 octobre 2026, avec 6 jours de stage et 2 
activités par jour, tous niveaux. Le document fourni mentionne le Boxing Center Portet-sur
Garonne comme lieu de stage initial.
Correction importante
Le document mentionne 11–16 ans, mais cette information est à corriger.
L’âge à retenir pour la page web sera :
8 à 16 ans
Cette correction devra être appliquée partout :
• page d’accueil ;
• pages clubs ;
• tunnel d’inscription ;
• CGV ;
• règlement intérieur ;
• autorisation parentale ;
• décharge liée à l’état de santé ;
• e-mails de confirmation.
3. Salles concernées
Deux salles accueilleront les stages enfants :
1. Boxing Center Portet-sur-Garonne
2. Boxing Center Minimes
La page d’accueil devra afficher deux blocs de redirection clairs :
• Stage enfants — BC Portet-sur-Garonne ;
• Stage enfants — BC Minimes.
Chaque bloc devra contenir un bouton visible :
• Voir le stage à Portet
• Voir le stage aux Minimes
4. Structure du site
Page d’accueil
La page d’accueil devra présenter globalement les stages enfants Boxing Center.
Elle devra mettre en avant :
• une semaine 100 % boxe ;
• un stage ouvert aux filles et garçons de 8 à 16 ans ;
• des activités encadrées ;
• des groupes adaptés selon l’âge, le niveau et l’expérience ;
• une ambiance sportive, éducative et sécurisée ;
• la présence de coachs et intervenants qualifiés ;
• la possibilité de réserver directement en ligne.
Le document source présente le stage comme une semaine axée sur la progression, le dépassement 
de soi et l’expérience sportive en groupe, avec technique, tactique, préparation physique, assauts, 
sac, cohésion, analyse vidéo, découverte du haut niveau, bowling et interclub.
Pages clubs
Créer deux pages internes personnalisées :
1. /stage-enfants-portet
2. /stage-enfants-minimes
Chaque page club devra contenir :
• présentation du stage ;

• tarifs ;
• infos pratiques ;
• matériel nécessaire ;

8. Parcours d’inscription en ligne
Le parcours devra être simple, clair et rassurant.
Étape 1 — Choix du club
Le parent choisit :
• Portet-sur-Garonne ;
• ou Minimes.
Étape 2 — Choix du tarif
Le parent choisit :
• tarif adhérent ;
• tarif non-adhérent.
Étape 3 — Ajout au panier
Le parent ajoute le stage au panier.
Étape 4 — Paiement
Le paiement intervient en premier.
Le parent règle le stage en ligne.
Étape 5 — Formulaire enfant
Après paiement, le parent remplit obligatoirement le formulaire d’inscription de l’enfant.
Étape 6 — Signature des documents
Le parent finalise l’inscription par validation / signature des documents obligatoires :
• CGV adaptées au stage enfants ;
• règlement intérieur du stage ;
• autorisation parentale ;
• décharge / déclaration relative à l’état de santé de l’enfant ;
• autorisation ou refus du droit à l’image ;
• acceptation des conditions de participation.
Étape 7 — Confirmation
Le parent reçoit un e-mail de confirmation avec :
• récapitulatif du stage ;
• club choisi ;
• nom de l’enfant ;
• dates ;
• horaires ;
• matériel à prévoir ;
• rappel des documents acceptés ;
• contact utile en cas de question.
9. Formulaire enfant à créer

• Nom ;
• Prénom ;
• Date de naissance ;
• Âge calculé automatiquement si possible ;
• Année de pratique : menu déroulant ;
• Observations : champ libre.
Menu déroulant — année de pratique
Prévoir :
• Débutant ;
• 1 an ;
• 2 ans ;
• 3 ans ;
• 4 ans ;
• 5 ans et plus.
Informations parent
• Téléphone parent 1 ;
• Téléphone parent 2, optionnel ;
• E-mail parent.
Observations
Champ libre pour indiquer :
• allergies ;
• traitement médical ;
• blessure ;
• problème médical ;
• information particulière ;
• niveau de pratique ;
• demande spécifique.
Le formulaire papier du document source prévoit déjà les informations participant, expérience en 
boxe, responsable légal, contact d’urgence, allergies, traitement médical, blessure ou problème 
médical. Ces éléments devront être adaptés au format numérique.

Ces documents devront être adaptés et validés par la direction avant mise en ligne.
